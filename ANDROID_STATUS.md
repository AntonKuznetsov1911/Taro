# Android — состояние работы

Дата: 02.11.2026. База: main `6feb2618cdf56e815ab02d8162a61d6c2fda0003`.
Рабочая ветка: `codex/android-app`. Версия: 1.3.0, versionCode 1,
package `com.antonkuznetsov.taro`, minSdk 24, targetSdk 36.

Реализованы переход на Expo 54 / React Native 0.81, нативное распознавание руки
MediaPipe и линий ONNX с моделями внутри APK, звук, камера и возврат из настроек
разрешений, безопасные отступы системных панелей, локальное напоминание в 09:00.
Рубашки карт на Android рисуются через react-native-svg. Фотографии, сохранённые
в историю, копируются из кеша в постоянные файлы приложения.

Добавлены JSON-копии с проверкой структуры и фотографиями. Прерванное восстановление
откатывается при следующем запуске до чтения данных интерфейсом. История на Android
хранится в файле с предыдущим снимком: это обходит ограничение одной строки SQLite.
Записи сохраняются последовательно; повторный ID не создаёт дубликат. Идентификаторы
изображений Metro заменены стабильными ID карт. Выключенное автосохранение соблюдается,
доступны ручное сохранение и сохранение при добавлении в избранное.

Подтверждено: TypeScript, проверка совместимости Expo, production web build,
36 unit-тестов и 10 проверок общего интерфейса в production-сборке.
`assembleRelease`, `bundleRelease`, `lintRelease` и четыре инструментальных теста
release APK прошли на Android 11 x86_64 с отключённой сетью. Тесты проверили
запуск настоящего пользовательского экрана, загрузку обеих моделей, ONNX-вывод
и 21 точку руки с согласованными RGBA-пикселями на фотографии Google MediaPipe,
сохранение/чтение ежедневного напоминания с JSON-данными без дубликатов.
APK: apksigner и zipalign с 16 КБ; AAB: jarsigner и bundletool validate — успешно.
Все 50 упакованных библиотек ARM64/x86_64 имеют выравнивание ELF LOAD не менее 16 КБ.

Вручную в эмуляторе проверены: полный профиль с клавиатурой и датой, расклад
на три карты с переворотами и толкованием, история и профиль после закрытия
без интернета, экспорт через системный выбор папки Android и восстановление
этой копии в чистую установку. Камера получает разрешение, снимает изображение
и передаёт его распознаванию; на кадре эмулятора корректно сообщает об отсутствии
руки. Это не проверка качества на настоящих снимках с телефона пользователя.
На физическом телефоне пользователя версия пока не проверялась.

Нативный звёздный фон не использует HTML/document. Наложения камеры находятся
рядом с CameraView: Expo Camera 17 не поддерживает дочерние элементы.
R8 сохраняет protobuf/MediaPipe/ONNX-классы, нужные моделям во время выполнения,
и сериализаторы Expo Notifications: иначе сохранение уведомления падало с
NotSerializableException для JSONObject.
Splash-ресурс API 33 отделён от базовых ресурсов; кастомный конфиг-плагин идёт
первым, поскольку Expo выполняет resource mods в обратном порядке.

Рабочая копия: `C:/Users/User/Documents/Codex/work/Taro`. На Windows нужны
короткие физические пути к исходникам и Gradle-кешу; subst не подходит.
Локальная одновременная сборка универсального APK/AAB использовала JVM 4–6 ГБ
и максимум два Gradle worker. Изменения опубликованы в ветке, черновик PR:
https://github.com/AntonKuznetsov1911/Taro/pull/6. Main, сайт и магазин не обновлялись.

Настоящий ключ подписи хранится отдельно от репозитория в папке outputs/android-signing
текущего чата. Не заменять его и не отправлять в GitHub.
