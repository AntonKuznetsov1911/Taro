🚂 Развертывание Taro на Railway

Простая пошаговая инструкция для деплоя backend

1 Откройте Railway и создайте проект

Нажмите кнопку ниже, чтобы открыть Railway:

🚀 Открыть Railway
  • Нажмите "Deploy from GitHub repo"
  • Выберите репозиторий AntonKuznetsov1911/Taro
  • Railway автоматически определит Python проект

2 Настройте переменные окружения

В Railway проекте перейдите во вкладку Variables и добавьте:

OPENAI_API_KEY
sk-ваш-openai-api-key
Получить OpenAI Key
MONGO_URL
mongodb+srv://user:password@cluster.mongodb.net/
Получить MongoDB
DB_NAME
taro
PORT
8000
⚠️ Важно: Если у вас нет MongoDB, вы можете добавить его прямо в Railway:
  • Нажмите "+ New" в вашем проекте
  • Выберите "Database" → "MongoDB"
  • Railway автоматически создаст MONGO_URL

3 Настройте команды сборки и запуска

Перейдите в Settings вашего сервиса:

Root Directory: / (оставьте пустым)

Build Command:
pip install -r backend/requirements.txt

Start Command:
cd backend && uvicorn server:app --host 0.0.0.0 --port $PORT

4 Разверните проект

  • Нажмите "Deploy"
  • Дождитесь завершения деплоя (2-5 минут)
  • Проверьте логи на наличие ошибок

5 Получите URL backend

После успешного деплоя:

  • Перейдите в Settings → Networking
  • Нажмите "Generate Domain"
  • Скопируйте URL (например: taro-production.up.railway.app)
✅ Проверьте работу API:
Откройте в браузере: https://your-app.up.railway.app/api/
Должно быть: {"message": "Taro API is running"}

6 Обновите frontend

После того как получите Railway URL, вернитесь сюда и скажите мне URL - я обновлю frontend автоматически!

Я создам файл frontend/.env с вашим backend URL
и запушу изменения на GitHub.
GitHub Actions автоматически пересоберет приложение.
